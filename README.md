[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

> "每一个选择，都创造一条新的世界线"

**Worldline Choice** 是一个通用的AI驱动互动叙事游戏引擎。它支持完全开放式的游戏体验，所有剧情、抉择点、选项都由AI实时生成，不预设固定故事情节。

## 🎮 游戏概述

### 1.1 游戏定位

| 项目 | 内容 |
|------|------|
| **游戏名称** | 世界线·抉择 (Worldline: Choice) |
| **游戏类型** | AI驱动互动叙事 / 文字冒险 (Interactive Fiction) |
| **核心体验** | 「你就是主角，重写传奇」 |
| **目标用户** | 18-35岁，喜爱剧情、历史、文学、RPG的游戏玩家 |
| **单局时长** | 15-45分钟（短篇）/ 1-2小时（长篇） |

### 1.2 核心概念

《世界线·抉择》是一款基于固定世界观的AI互动叙事游戏。玩家在熟悉的历史、名著或原创世界中扮演关键角色，通过**预设选项**或**自由输入**来推动剧情发展。AI根据玩家的每个选择实时生成后续剧情，最终导向不同的结局。

**一句话描述**：
> 在三国成为枭雄，在西游改写天命，在克苏鲁对抗疯狂——你的每个选择，都将创造独一无二的世界线。

### 1.3 游戏特色

1. **混合抉择系统**：4个精心设计的预设选项 + 1个自由输入通道，兼顾引导性与自由度
2. **动态叙事**：AI实时生成剧情，每次游玩都是全新体验
3. **状态追踪**：属性、关系、道具、标签多维度记录玩家选择的影响
4. **多结局收集**：每条世界线包含5-12个不同结局，鼓励重复游玩
5. **正版世界观**：支持历史架空、名著改编、原创世界等多种背景

### 2.2 单局游戏结构

| 游戏模式 | 章节数 | 预计时长 | 结局数 |
|----------|--------|----------|--------|
| **短篇故事** | 3章 | 15-20分钟 | 3-5个 |
| **中篇冒险** | 5章 | 40-60分钟 | 5-8个 |
| **长篇史诗** | 7-9章 | 1-2小时 | 8-15个 |

### 2.3 场景设计标准

每个场景是剧情推进的基本单位，核心目的是**呈现冲突并让玩家做出影响走向的选择**。

#### 场景构成要素

| 元素 | 描述 | 作用 |
|------|------|------|
| **场景描述** | 100-200字的情境描写 | 交代背景、营造氛围、呈现当前局势 |
| **核心冲突** | 当前场景需要解决的主要矛盾 | 为抉择选项提供设计依据 |
| **关键信息** | 玩家需要知道的重要情报 | 帮助玩家理解选择的后果 |
| **在场角色** | NPC及其立场、状态 | 影响玩家可以互动的对象 |
| **抉择选项** | 4个不同方向的预设 + 1自由输入 | 见抉择系统章节 |
| **隐性铺垫** | 为后续剧情埋下的伏笔 | 增加重玩价值和剧情深度 |

#### 场景设计原则

**1. 每一场景必须有真正的选择**
- 避免"伪选择"（选什么都一样的剧情）
- 每个选项都会导致不同的后续场景

**2. 冲突要清晰**
- 玩家进入场景就知道"问题是什么"
- 选项直接回应这个核心冲突

**3. 信息要充足但不过度**
- 让玩家有能力做出有依据的选择
- 但保留不确定性，增加戏剧性

## ⚔️ 抉择系统详解

### 3.1 混合抉择模式

每个抉择点采用**固定格式**：

```
┌──────────────────────────────────────────────────────────────┐
│  【抉择点名称】                                               │
│                                                              │
│  场景描述文本...                                              │
│                                                              │
│  ┌────────────────────────────────────────────────────────┐  │
│  │  A. 【行动类】具体行动描述                               │  │
│  │     标签：勇敢 · 可能触发战斗                             │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  B. 【对话类】具体对话/交涉描述                          │  │
│  │     标签：智慧 · 可能获得情报                             │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  C. 【观察类】观察/等待/暗中行动描述                     │  │
│  │     标签：谨慎 · 可能发现隐藏要素                         │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  D. 【特殊类】基于当前状态的特殊选项                     │  │
│  │     标签：[持有特定道具/达成特定条件时显示]               │  │
│  ├────────────────────────────────────────────────────────┤  │
│  │  💭 我另有打算...（点击输入自定义行动）                  │  │
│  └────────────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────────────┘
```

### 3.2 四类预设选项设计规范

抉择点的4个预设选项应围绕**当前场景的核心冲突**设计，每个选项代表一条**不同的剧情发展方向**。

#### 选项分类模式（按剧情功能）

**模式一：阵营/立场选择**
```
场景：两股势力冲突，你被卷入其中
A. 【支持甲方】理由/方式
B. 【支持乙方】理由/方式
C. 【保持中立】寻找第三条路/暂时观望
D. 【特殊条件】基于状态的独特选择
```

**模式二：策略/方法选择**
```
场景：需要解决一个难题或达成目标
A. 【直接方案】正面突破，高效但风险高
B. 【迂回方案】侧面渗透，耗时但稳妥
C. 【非常规方案】利用环境/第三方/诡计
D. 【特殊条件】基于能力的专属方案
```

**模式三：价值观/道德选择**
```
场景：面临伦理困境或利益冲突
A. 【利己】优先保障自身/己方利益
B. 【利他】牺牲自己帮助他人
C. 【平衡】寻求多方共赢（难度更高）
D. 【特殊条件】基于信仰/原则的立场
```

**模式四：风险/收益选择**
```
场景：机会出现，需要决策
A. 【激进】高风险高回报，梭哈一搏
B. 【稳健】中等风险中等收益，稳中求进
C. 【保守】规避风险，宁可错过也不犯错
D. 【特殊条件】基于信息的特殊判断
```

#### D类选项：条件触发式特殊路线

D选项不一定是"特殊道具/属性"，更可以是**基于之前选择解锁的独特剧情方向**。

| 触发类型 | 示例场景 | D选项示例 |
|----------|----------|----------|
| **前置关系** | 与某NPC好感度达标 | 【求助】关键时刻，李典率部杀到（需与李典好感≥30） |
| **前置选择** | 之前做过特定选择 | 【兑现承诺】用你之前救下的那人的情报破局 |
| **身份专属** | 特定职业/出身 | 【以商人的身份】提出一个双方都无法拒绝的交易方案 |
| **隐藏信息** | 之前获得过情报 | 【揭穿】你已经知道这一切都是陷阱 |
| **性格累积** | 标签累积达标 | 【以德服人】你的仁德之名早已传开 |
| **物品关联** | 持有特定道具 | 【传国玉玺在此】举起玉玺，各方势力不得不重新考虑 |

### 3.3 自由输入系统

#### 输入解析逻辑

AI需要识别并归类玩家的自由输入：

| 输入类型 | 识别关键词 | 处理方式 |
|----------|-----------|----------|
| **战斗行动** | 打、杀、攻、砍、射、战 | 计算战力，触发战斗判定 |
| **对话交涉** | 说、问、谈、劝、骗、求 | 分析话术，进行说服判定 |
| **潜行观察** | 看、躲、藏、等、跟、查 | 进行隐匿/观察判定 |
| **物品使用** | 用、吃、喝、点、扔、给 | 检查物品栏，触发效果 |
| **移动位置** | 走、跑、跳、爬、进、退 | 改变场景位置 |

#### ⚖️ 严格可行性评估

自由输入选项会进行**严格客观的可行性评估**：

- ✅ **客观能力检查**：玩家是否有执行此行动所需的技能/能力/物品
- ✅ **情境限制检查**：环境、时间、物理限制是否允许
- ✅ **信息掌握检查**：不能假设玩家知道未发现的秘密
- ✅ **合理性评估**：符合游戏世界的基本逻辑和物理法则
- ✅ **不刻意迎合**：不会因为玩家想这么做就让其轻易成功
- ✅ **不刻意刁难**：不会因为玩家想这么做就故意使其失败

### 3.4 抉择后果系统

每个选择都会产生**显性**和**隐性**后果：

```
选择后果层级：

显性后果（立即反馈）
├── 场景变化：进入新场景/触发战斗/改变环境
├── 属性变化：武力±X / 智力±X / 魅力±X / 声望±X
├── 关系变化：与XX好感±X
├── 物品获得/失去：获得【XX】/ 失去【XX】
└── 即时事件：受伤、中毒、被发现等

隐性后果（长期影响）
├── 性格标签累积：勇敢+1、狡诈+1、仁慈+1
├── 剧情标记：记录关键选择，影响后续选项
├── 路线锁定：逐步确定阵营/结局方向
└── NPC态度：影响未来与相关NPC的互动
```

## 👤 角色与状态系统

### 4.1 角色创建

开局时玩家需要创建/选择角色：

| 身份 | 属性加成 | 特点 |
|------|----------|------|
| **谋士** | 智力+5 | 擅长谋略、解锁智力相关选项 |
| **武将** | 武力+5 | 擅长战斗、解锁武力相关选项 |
| **游侠** | 魅力+5 | 擅长社交、解锁魅力相关选项 |
| **商人** | 金钱+100 | 擅长交易、解锁商业相关选项 |

### 4.2 属性系统

| 属性 | 说明 | 影响范围 | 初始值范围 |
|------|------|----------|------------|
| **武力** | 战斗能力 | 单挑胜率、战斗选项成功率 | 10-20 |
| **智力** | 谋略能力 | 识破陷阱、特殊选项解锁 | 10-20 |
| **魅力** | 人格魅力 | 说服成功率、NPC好感获取 | 10-20 |
| **声望** | 江湖名气 | 特殊NPC态度、势力选择 | 0-10 |

### 4.3 关系系统

重要NPC拥有独立的好感度：

```
关系等级：

憎恨 [-100, -50)  → 敌对行动，可能追杀玩家
冷淡 [-50, 0)     → 冷淡对待，交易/对话受限
中立 [0, 20)      → 普通对待，基础互动
友善 [20, 50)     → 友好对待，提供额外帮助
信任 [50, 80)     → 深度交流，解锁特殊剧情
生死之交 [80, 100] → 无条件支持，可能牺牲自己

好感度变化：
• 完成委托：+5~+15
• 选择帮助：+5~+20
• 赠送礼物：+3~+10（取决于礼物价值）
• 背叛伤害：-20~-50
• 理念冲突：-5~-15
```

### 4.4 标签系统

记录玩家的行为模式和关键选择：

| 标签类型 | 示例 | 作用 |
|----------|------|------|
| **性格标签** | 仁慈、残忍、狡诈、正直、勇敢、谨慎 | 影响NPC对玩家的态度 |
| **阵营标签** | 曹魏势力、袁氏门客、自由身、汉室忠臣 | 解锁对应势力选项 |
| **事件标签** | 乌巢功臣、官渡幸存者、颍川义士 | 特定剧情触发条件 |
| **状态标签** | 负伤、中毒、被通缉、被悬赏 | 临时状态，影响当前游戏 |

### 4.5 物品系统

```
物品分类：

【消耗品】
├── 金疮药：恢复轻伤
├── 解毒丹：解除中毒
├── 酒：临时魅力+3（战斗时武力-2）
└── 干粮：维持体力

【装备】
├── 武器：影响战斗力（剑、刀、枪、弓）
├── 防具：影响受伤概率（轻甲、重甲）
└── 饰品：特殊效果（玉佩+魅力、锦囊+智力）

【任务物品】
├── 信物：证明身份
├── 情报：解锁特殊选项
├── 宝物：高价值交易物
└── 关键道具：剧情必需品

【特殊物品】
└── 如【传国玉玺】：解锁称帝选项
```

### 5.3 结局设计

每条世界线包含多个结局，分为三类：

| 结局类型 | 数量 | 达成难度 | 示例 |
|----------|------|----------|------|
| **主线结局** | 3-5个 | 中等 | 统一北方、战死沙场、归隐田园 |
| **隐藏结局** | 2-4个 | 困难 | 三国归晋提前、神秘力量介入 |
| **彩蛋结局** | 1-3个 | 随机/趣味 | 打破第四墙、穿越现代、全员喜剧 |

**结局判定条件示例**：

```yaml
结局：【一统北方】
条件：
  - 路线：投曹 或 自立后归曹
  - 声望：≥80
  - 官渡之战：成功奇袭乌巢 或 击败袁绍
  - 存活：是

结局：【乱世枭雄】
条件：
  - 路线：自立
  - 声望：≥60
  - 拥有自己的城池（特定剧情标记）
  - 曹操和袁绍均未统一
```

## 🤖 AI叙事系统

### 6.1 核心Prompt架构

引擎生成三种Prompt供AI使用：

**系统Prompt** (`get_system_prompt()`)
- 包含世界观、当前状态、历史记录
- 用于生成新的场景和选项

**行动Prompt** (`get_action_prompt()`)
- 包含当前场景、玩家输入
- 用于评估可行性并推演后果

**结局Prompt** (`get_ending_prompt()`)
- 包含完整游戏回顾
- 用于生成结局剧情

### 6.2 AI生成流程

1. **场景生成**：基于世界观和当前状态生成场景
2. **冲突识别**：自动识别场景中的核心冲突
3. **选项生成**：生成4个不同方向的选项（A/B/C/D）
4. **可行性评估**：对自由输入进行严格客观的可行性检查
5. **后果推演**：推演行动后果，更新状态
6. **结局判定**：判断是否达到结局条件

### 6.3 上下文管理

为保证剧情连贯性，AI需要维护：

```
上下文窗口（分层组装）：
┌─────────────────────────────────────────────────┐
│ 最近5回合详细记录（100%保留）                    │
├─────────────────────────────────────────────────┤
│ 最近2-3个阶段摘要（中期回顾）                    │
├─────────────────────────────────────────────────┤
│ 全部里程碑（剧情走向）                           │
└─────────────────────────────────────────────────┘
```

## 💾 存档系统

### 8.1 分层历史存储

采用**三层存储架构**，确保不丢失任何回合信息：

```
┌─────────────────────────────────────────────────────────┐
│ 【原始数据层】raw_history[]                              │
│   - 永久保存所有回合的完整记录                            │
│   - 即使1000回合也不会删除                               │
├─────────────────────────────────────────────────────────┤
│ 【阶段摘要层】history_summaries[]                        │
│   - 每10回合自动生成一个摘要                              │
│   - 用于AI中长期上下文                                   │
├─────────────────────────────────────────────────────────┤
│ 【里程碑层】milestones[]                                 │
│   - 记录关键剧情节点（投曹、官渡胜利等）                   │
│   - 用于快速了解剧情走向                                  │
└─────────────────────────────────────────────────────────┘
```

**AI上下文组装**：近期详细(5回合) + 阶段摘要(2-3个) + 里程碑(全部)

### 8.2 存档规则

1. **原始历史永不删除** - `raw_history` 数组永远不会被截断
2. **自动精简摘要** - 每回合自动生成摘要
3. **定期阶段摘要** - 每10回合合并生成
4. **里程碑自动追踪** - 关键flag自动记录

### 安装

```bash
git clone https://github.com/caoyachao/worldline-choice.git

```

### Python API 使用

```python
from worldline_engine import WorldlineEngine

# 创建游戏引擎
game = WorldlineEngine()

# 开始游戏
game.start_game(
    world_setting="魔兽世界 - 巫妖王之怒时期",
    player_role="潜行者",
    player_name="玩家"
)

# 获取AI Prompt用于生成场景
system_prompt = game.get_system_prompt()

# 处理玩家行动（AI返回的响应）
result = game.process_action(
    player_input="调查那个神秘女子",
    ai_response={
        "intention": "调查",
        "feasible": True,
        "narrative": "你悄悄跟踪神秘女子，发现她进入了黑帮据点...",
        "consequences": {
            "attribute_changes": {"智力": 1},
            "secrets_learned": ["女子是黑帮成员"]
        }
    }
)

# 保存游戏
game.save_game("save_001")
```

## 📝 设计原则

### 1. 严格可行性评估
- 不刻意迎合玩家，也不刻意刁难
- 完全基于客观事实判断
- 失败也应该产生有意义的后果

### 2. D选项（特殊路线）的代价
- 不是"万能钥匙"
- 有真实的代价和风险
- 可能影响最终结局

### 3. 开放式叙事
- 不预设固定剧情
- AI根据玩家行为实时生成内容
- 每个玩家体验独一无二

### 4. 永不丢失历史
- 所有回合完整记录永久保存
- 分层摘要用于AI上下文
- 支持完整复盘
